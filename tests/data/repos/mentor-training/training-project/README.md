# Repair Desk

Учебное приложение Cyber Garden 2026 для статической проверки Kotlin и Gradle Kotlin DSL. Приложение намеренно содержит небезопасный код. Записи, идентификаторы и встроенные значения полностью вымышлены. Используйте его только в учебных целях.

Repair Desk ведёт записи о ремонте велосипедов. Гость видит каталог услуг, клиент просматривает заказ, сотрудники готовят выдачу. Синтетические данные хранятся в H2 in-memory. Внешние интеграции моделируются локально.

Для статического анализа достаточно исходников, конфигурации Spring и файлов Gradle. Учебная область SCA включает явно объявленные зависимости. Если хотите собрать приложение, установите JDK 21 и выполните из папки `training-project/` команду `./gradlew --no-daemon clean bootJar` на Linux или `.\gradlew.bat --no-daemon clean bootJar` в Windows PowerShell. При первой сборке Gradle может скачать дистрибутив и зависимости.

Пример настройки внешней интеграции в документации: `apiKey = "YOUR_API_KEY"`. Образец обозначает место подстановки значения.
